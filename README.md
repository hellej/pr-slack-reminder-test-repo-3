# pr-slack-reminder-test-repo-3

Live test fixture for [pr-slack-reminder-action](https://github.com/hellej/pr-slack-reminder-action).
The open `[fixture]` PRs here exercise stale approvals. Do not merge or close them.
They are opened by `github-actions[bot]` through the `create-fixture-pr` workflow and reviewed by `hellej`.
The `[fixture] approved, failing required check` PR targets `fixture/required-check-base`, whose ruleset requires the `fixture-check` status, which is set to failure by hand.
Everything in this repository is test data.
